Statistical analysis
Positional enrichment downstream of the P/G–D/E/T motif was analysed in peptides carrying an N-terminal P/G–D/E/T motif (positions are numbered from the first residue after the initiator methionine, so that P or G is position 1 and D/E/T is position 2). The occurrence of each of the 20 amino acids at positions 3–23 was compared between motif-bearing UBR3 candidates (n=20) and motif-bearing library peptides that were not stabilised upon UBR3 loss (n=193). Statistical significance was assessed by two-sided Fisher's exact test (scipy.stats.fisher_exact, SciPy v1.17), comparing the number of occurrences in candidate substrates versus non-substrates for each amino acid at each position. Fold change was calculated as the ratio of amino acid frequency in candidates to frequency in non-substrates. p values were corrected for multiple testing across all 416 testable amino acid–position combinations by the Benjamini–Hochberg procedure (statsmodels v0.14).

A significance sequence logo (Fig. 15b) was generated using logomaker v0.8 in Python 3, where letter height is proportional to −log10 p; only amino acids enriched in candidates at p < 0.05 are shown, and all others were set to zero. Letters are stacked with the most significant amino acid on top and colored by −log10 p using the same custom warm colormap as the heatmaps.

−log10 p values for all 20 amino acids at positions 3–23 were displayed as a heatmap using Matplotlib's imshow, with a custom warm colormap (off-white-to-dark-red, range 0–5) (Fig. 16c). Amino acids depleted in candidates were set to the lowest color. Cells with p < 0.05 are annotated with their fold change. Significance annotations- *p < 0.05, **p < 0.01, ***p < 0.001.

Amino acids were grouped into six biochemical categories: basic (K, H, R), acidic (D, E), aromatic (F, Y, W), aliphatic (G, P, A, M), hydrophobic (V, L, I) and polar (S, T, C, N, Q). Category enrichment at each position was tested by two-sided Fisher's exact test as above, with Benjamini–Hochberg correction across all 126 category–position combinations, and displayed as a heatmap as in Fig. 16c (Fig. 17b).

Each figure was also generated for positions 3–11 only, using the same p values; q values were not recomputed for the reduced window.
